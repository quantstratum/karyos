# Contributing to Karyos

## Changelog

Pull requests do not edit `CHANGELOG.md`. A pull request adds its entry as
a fragment in `changelog.d/` (see `changelog.d/README.md`), and the release
folds the fragments into `CHANGELOG.md`. The entries already under
`[Unreleased]` stay there. An open pull request that still edits
`CHANGELOG.md` moves its entry to a fragment at its next rebase.
