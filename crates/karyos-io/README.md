# karyos-io

Backend traits, the sockets backend, hardware timestamps and timed transmission; the uring and xdp features add the other backends.

This crate is internal to Karyos and unstable in alpha, with no compatibility promise; depend on the `karyos` facade instead.

Part of [Karyos](https://github.com/quantstratum/karyos). Licensed under Apache-2.0.
