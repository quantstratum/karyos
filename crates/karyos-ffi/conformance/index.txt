# The §13 contract rows of the C ABI (SPEC.md §13, "C ABI boundary" and
# "Binding conformance") and the scenarios that cover them. One row per
# line: the row's name, then `:`, then the scenario ids that cover it, or
# `pending` and the batch of quantstratum-docs:
# karyos/design/ffi-gap-analysis.md that brings them.

abi version: abi.version op.library.version
typed status codes: abi.version.null status.text handle.wrong.kind publication.typed.statuses publication.timed.offer subscription.options.typed.statuses offer.options.typed.statuses conflated.typed.statuses archive.typed.statuses publication.concurrent outcomes.typed.statuses conflated.client.view op.publication.concurrent op.outcomes
use after close: handle.use.after.close publication.use.after.close claim.use.after.close op.use.after.close op.parent.close
double close: handle.double.close claim.double.commit op.double.close op.conflated
older protocol version refused at admission: pending a driver the suite can start (F5 or a test driver); tests/connect.rs covers it on Linux
reentrant poll: subscription.poll.reentrant
bounded poll stops on callback failure: subscription.poll.bounded
kept fragment pointer never refers to a shared mapping: pending a runner that can see the library's mappings, which a portable one cannot; src/abi/tests.rs a_subscription_delivers_each_message_from_its_private_copy covers it
panic poisons the handle and does not unwind: pending a fault hook, since no call can make libkaryos panic and the ABI exports none (DESIGN); the Rust tests of boundary.rs, the handle tables' poison and api/driver cover it
older minor ABI client against a newer library: pending the ABI manifest test of the first released header
