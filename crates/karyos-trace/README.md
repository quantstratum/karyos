# karyos-trace

Trace context, bounded journals, clock calibration and HDR aggregation.

Its analysis surface (the trace report, journal sources, histograms and
clock calibration) is part of the supported alpha API; the crate
documentation lists exactly which modules and types, and the rest of the
crate is internal and unstable in alpha. Alpha releases may still break
APIs, wire formats and shared-memory layouts.

Part of [Karyos](https://github.com/quantstratum/karyos). Licensed under Apache-2.0.
