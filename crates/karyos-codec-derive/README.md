# karyos-codec-derive

The `#[derive(Message)]` macro of the Karyos message codec, compile time
only. It is published because `karyos-archive` uses it; it is internal and
unstable in alpha, with no compatibility promise of its own. Alpha releases
may still break APIs, wire formats and shared-memory layouts.

Part of [Karyos](https://github.com/quantstratum/karyos). Licensed under Apache-2.0.
