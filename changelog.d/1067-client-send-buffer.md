### Added

- `IpcConfig::client_send_buffer` (karyos#1067): the send buffer (`SO_SNDBUF`) the driver requests on each accepted admission connection, nonzero and at most `i32::MAX` (else `InvalidConfig`). The kernel decides the size it keeps (Linux caps the request at `net.core.wmem_max`, doubles it and applies its minimum); that size bounds, through the kernel's socket memory accounting, what one client's unread messages take, and so when a client that stopped reading is retired. `None`, the default, leaves the host's `wmem_default`, as before. A connection whose buffer cannot be set is closed, and counts as one of the step's accept attempts. `a_client_that_stops_reading_is_retired` now uses 4096 bytes, so it no longer depends on the host: with a 128 MiB `wmem_default` the driver's socket never filled within its deadline.
