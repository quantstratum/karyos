### Added

- The agent submits a product Cluster's admin command (`cluster-command OPID CLUSTER COMMAND PARAMETERS [REASON]`, capability `cluster-command`): the product attaches its Cluster with a `ClusterGateway` that registers the commands it accepts, each for operators or for administrators only, and the agent forwards only those, unread, under the caller's operation id. The request is journalled durably before it is sent (without a journal it is refused, unsent), its outcome after it: sequenced with the Cluster's log index and term, the product's reply and the evidence digest the product attached, shown in the answer; refused with the product's code; or unknown, never success, when no answer comes. A caller without the command's authority, an unregistered command, an unknown Cluster and a used operation id are refused and journalled with nothing sent (R-CORE-41, karyos#772).
