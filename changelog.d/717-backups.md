### Added

- Backups of a Cluster node to remote storage and a rebuild from them (`karyos_cluster::backup`, karyos#717). `export` takes a stopped node's latest snapshot and the committed log after it through the Archive's `ObjectStore`. It first checks the snapshot's term against the log and that the commit reaches it, and refuses a remote that already holds an export. Each object is read back and checked against its CRC-32C before it counts, and the manifest goes last. `verify` checks the manifest's coverage (one snapshot, then log ranges from the base's next index to the top with no gap) and every object's bytes and contents, one at a time. `rebuild` writes only into empty directories, so it never installs over or purges a node's state, and in particular nothing an Archive hold keeps. It checks the whole export before writing, and refuses a damaged object by naming its range. Each reports the index and term reached and what it does not include.
