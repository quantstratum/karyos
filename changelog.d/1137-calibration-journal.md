### Added

- A durable calibration journal (karyos#1137, ADR-0098 items 3 and 5): `karyos-tools calibrate append --journal <dir>` appends records (the 18 words `calibrate phc` prints, given as words or piped on standard input) durably, making the journal if absent, and `karyosd --archive-calibration-journal <dir>` gives the Archive agent that journal as its calibration source, read again at each snapshot, so records appended while the daemon runs reach groups' time evidence without the host calling `ArchiveHandle::set_calibration_source`. The journal is a directory holding one Archive segment store recording (recording 1, one 144-byte record per write, each covered by its index entry's CRC-32C, synced before the append returns), the layout the time evidence entries' store uses; a torn tail is never read and is cut by the next writer, damage before it is refused, a record type this build does not know is kept and skipped, and a known type that does not decode is never appended. One writer at a time holds `writer.lock` in the directory. `karyos_archive::integrity::calibration_journal` provides `CalibrationJournal`, `read` and `JournalSource`.
