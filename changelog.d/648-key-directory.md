### Added

- The wire authentication key directory, the durable key state and reload, in `karyos_driver::wire_keys::{state, store}` (part of karyos#648; quantstratum-docs: karyos/design/wire-key-files.md sections 2.1, 2.3, 2.4 and 2.6). `karyos_sys::secure_dir` opens the directory once by descriptor, walking the path from `/` with `O_DIRECTORY | O_NOFOLLOW`, and checks every ancestor, the directory and each file by `fstat` on its own descriptor. The store fails closed on every path: a refused or malformed file is absent, a `revoked` list that does not validate disables every key, an admitted file that changes is disabled for good, and a failed commit disables every key until one succeeds. Tombstones, disable markers, retirements, the epoch lineage and keyed fingerprints are committed durably (temporary file, `fsync`, rename, directory `fsync`) before a new admission is used. Nothing enables a channel yet.
