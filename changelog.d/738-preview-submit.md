### Added

- The agent previews a guard close or reopen (`guard-close-preview` and `guard-reopen-preview`, capability `guard-preview`): the guard's state as last followed in the driver's audit, the epoch after, and a 128-bit token bound to the principal, the target (driver instance and guard) and the parameters, valid for 60 s; a field it cannot read is `"unavailable"`, never a default. `submit OPID TOKEN guard-close|guard-reopen DIR GUARD [REASON]` (capability `submit`) performs exactly the previewed operation under the caller's operation id, at the previewed epoch, which the driver checks with the transition (`GuardCloseAt`, `GuardReopen`); a mismatched principal, target or parameters, a new driver instance, an unknown or expired token and a reused id are refused with nothing sent (R-CORE-18, karyos#738).
