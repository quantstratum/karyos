### Added

- `GuardCloseAt` (CnC `0x16`) closes a guard only if it is still open at the epoch the client names, refused with the new `GuardNotOpenAt` (detail: the current guard word) when it moved since; `karyos_sys::guard::close_at` and `ClientConductor::guard_close_at` back it. The admission protocol version is 6 (`KARYOS_PROTOCOL_VERSION`, C ABI 0.1.8): an alpha.4 driver, which speaks version 5, refuses a client of this release at `Hello` rather than retiring it on the unknown command. The first part of preview calls and caller-chosen operation ids (karyos#738).
